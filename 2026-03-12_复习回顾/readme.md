## 1. 异常处理回顾（3月9日内容）
- 多catch顺序：从具体异常（InputMismatchException、ArithmeticException）到兜底Exception
- finally强制执行机制（即使有return也会执行）
- throw（真抛出异常） vs throws（声明可能异常）
- 自定义异常（AgeException） + getMessage()
- 核心理解：异常不是流程控制工具，而是“救护车”机制

## 2. 一维数组回顾（3月10日内容）
- 数组长度不可变，但数组名（引用）可以重新指向新数组（扩容本质）
- 引用赋值是地址共享（arrb = arr 后修改一方，另一方也变）
- 基本类型数组 vs 引用类型数组差异（int[]直接存值，User[]存地址需再new）
- 实战：插入元素（扩容+后移）、删除元素（新建数组+后移覆盖）、线性查找、二分查找

## 3. 二维数组 + 二重循环回顾（3月11日内容）
- 二维数组本质：数组的数组（外层管行，内层管列）
- 二重循环遍历 + 对称赋值
- 回型方阵实现：
  - 第一版（下标偏移 + 写死10以内）
  - 第二版优化（下标对齐 + n-1-j公式，奇偶通用）
  - 层数规律：Math.min(i, j)（距离边缘最近步数）
- 核心理解：二维数组像表格，二重循环是其主要操作方式
