1. 引用类型数组 (Reference Array)
栈 (Stack)：存储数组变量名，其值为数组在堆中的起始地址。

堆 (Heap) - 第一层（数组格子）：根据 起始地址 + 下标 * 偏移量 找到对应的格子。格子里存储的是 实例对象的内存地址。

堆 - 第二层（对象实体）：程序根据格子里的地址再次跳转，定位到真正的对象，从而读取其中的成员变量（如 id, maxSalary）。

寻址特征：两次跳转（二跳寻址）。

2. 二维数组 (Multi-dimensional Array)
栈 (Stack)：存储变量名，其值为**大数组（行数组）**在堆中的起始地址。

堆 - 第一层（行格子）：每个格子里存储的是对应**子数组（列数组）**的内存地址。

堆 - 第二层（列格子）：程序跳转到子数组，根据下标找到存储具体数据的格子（如果是 int 则直接拿值，如果是对象则继续跳转）。

寻址特征：至少两次跳转。在 Java 中，二维数组本质是“数组的数组”，空间不一定连续。

3. ArrayList
栈 (Stack)：存储 ArrayList 引用，指向堆中的 ArrayList 实例对象。

堆 - 第一层（对象内部）：在 ArrayList 实例的空间内，包含一个名为 elementData 的成员变量，它是一个 Object[] 数组的引用。

堆 - 第二层（底层数组）：程序先拿到 elementData 的地址，跳转到这个真实的数组空间。

堆 - 第三层（对象实体）：由于是 ArrayList<Job>，数组格子里存的是 Job 的地址，需再次跳转到 Job 实例。

寻址特征：比原生引用数组多出一次在对象内部获取数组引用的步骤。

总结对比：

基本类型数组 (int[])：栈 → 堆（直接拿值），路径最短。

引用类型/二维结构：都是“地址指向地址”的连锁反应，通过**指针（Pointer/Reference）**实现非连续空间的访问。
